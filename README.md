# LangUp — Learn English Website

React + Vite + Firebase (frontend) — full English learning site.

## Sections
Home, Vocabulary, Grammar, Courses, Tests, Listening, Reading, Speaking, Profile, Login/Register, Admin + Dark/Light, 3 levels, XP, saved words, daily tasks.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
```

## Firebase
Paste your config into `src/firebase.js` and uncomment init code. Currently auth/data uses localStorage so site works without Firebase.
